# Offline PDF Converter (v4.2)

Windowsで「オフライン」「exe単体」のまま使える構成を維持し、保存・取消・プレビュー・日本語フォントの安定性と、実際の配布exeの検証範囲を改善しました。

## 改善

- 日本語フォントが導入されていないWindowsでもOCR文字層を保持できるよう、SIL OFL 1.1のZen Kaku Gothic New Regularをexeに内蔵しました。追加インストール・ダウンロードは不要です。
- 出力名と同名のフォルダがある場合も、上書きせず別名で保存します。
- PDF画像化・分割を途中で中止した場合、保存済みファイル数を結果に正しく表示します。
- 異常なページ範囲（`1--3`、記号のみ、範囲外など）を拒否します。巨大な範囲を走査する前に検証します。
- PDFプレビューを切り替えた場合や中止・終了時に画像を解放し、古い処理結果で表示を更新しません。
- 処理中は入力と操作設定を固定します。処理中に閉じた場合は中止してから終了します。
- ファイル選択、保存先選択、編集画面、文字コピーの例外処理を改善しました。

## オフライン・exe単体

Windows版は.NET、OCRモデル、ONNX実行部品、Visual C++ CRT、日本語OCR用フォントをexeに含めます。実行時のネット接続、モデル取得、追加ランタイム導入は不要です。ZIP内のマニュアルは説明用で、動作に必要な実行ファイルはexe一つです。Windows OS部品と利用者の一時領域への書き込みは必要です。実行時にネイティブ部品とモデルを自動展開します。

## リリース前の検証

公開は次の検証がすべて成功した配布物だけを対象とします。実行結果のJSONをリリースに添付します。

- Windows Server 2022と2025で同じ配布exeを、exeだけの新規フォルダ・新規展開先・OSのみのPATHから実行。
- Windows Firewallで対象exeの送受信を全プロファイルで遮断し、OCR・主要機能・実ウィンドウの検証を実行。
- 4言語OCR、検索可能PDF、対象外ページ保持、見た目の一致、パスワード付き入力、異常入力、上書き防止、取消を検証。
- 配布exeからPNG/JPEGの全対応解像度、画像→PDFの全ページ設定、結合・分割・削除・抽出、文字・図形追加を実行。
- 実際のAvaloniaウィンドウと操作イベントでテーマ、プレビュー連続切替、変換の開始と結果画面、OCR、文字選択・クリップボードへのコピー、処理中の終了を確認。
- 同梱OCR・CRT・フォントとライセンスのハッシュ、CRTの実際の読み込み元、単体exe構成、ZIP内容・ハッシュを検証。
- macOS版の検索可能PDFと配布アプリの機能検証も実行。

## 検証の限界と既存の制約

これらは検証対象での結果であり、全PC・全PDFでエラーやバグが一切発生しない保証ではありません。破損した入力、誤ったパスワード、書込権限不足やディスク不足などは、正常な出力を保証できずエラーとして案内します。

Windows 10/11の実機、Visual C++未導入のクリーンVM、PC全体のネットワーク切断は、このCI検証とは別の未確認項目です。GUI検証は実ウィンドウと操作イベントの自動検証で、マウス・タッチ・OSファイル選択画面のすべての操作を網羅しません。

OCRモデルと認識精度は4.1から変更していません。認識結果の直接修正、元PDF本文の直接編集は未対応です。既存文字があるページはスキップします。元の暗号化・閲覧パスワードは出力に引き継がず、署名・目次・文書単位のフォーム構造の保持は保証しません。Mac版はApple Silicon向け・ad-hoc署名で、公証は未実施です。

4.0・4.1のリリースと配布ファイルは保持します。
