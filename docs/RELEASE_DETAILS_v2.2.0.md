## Offline PDF Converter v2.2.0

v2.1.0以降のPDF編集機能を拡張したリリースです。

### 主な変更

- PDF編集の操作名を「テキスト追加」から「文字・テキストを追加」に変更
- PDFページ編集画面のプレビュー画質を向上
- プレビュー画面の拡大・縮小に対応
- プラス / マイナスボタンでの拡大・縮小に対応
- Ctrl + マウスホイールでの拡大・縮小に対応
- トラックパッドのピンチイン / ピンチアウトでの拡大・縮小に対応
- ページプレビューのリスト表示からも編集画面を開けるように変更

### テキスト編集

- テキストボックスを常に最前面レイヤーに表示
- テキストボックスのコピー / 貼り付けに対応
- Ctrl + C / Ctrl + Vでテキストボックスを複製可能
- Ctrl + Zで直前の編集を取り消し可能
- フォントの太字と下線に対応
- Ctrl + Bで太字を切り替え可能
- Ctrl + Uで下線を切り替え可能
- テキスト色のデフォルトを黒に設定

### 図形編集

- 四角形、角丸四角形、丸、線の追加に対応
- 図形の移動、リサイズ、コピー / 貼り付けに対応
- Ctrl + C / Ctrl + Vで図形を複製可能
- 図形の塗り潰し色、境界線の色、境界線の太さを設定可能
- 塗り潰し色や境界線の色に「色なし」を設定可能
- 図形の回転に対応
- 線の始点と終点を個別に調整可能
- Shiftを押しながら線を調整した場合、45度刻みで角度を保持
- 四角形と丸の初期サイズを縦横同じ比率に変更
- Shiftを押しながら図形をリサイズした場合、縦横比を保持
- 角丸四角形を追加
- 角丸四角形の角の丸み調整に対応
- 角丸四角形を小さくした場合でも形が崩れないよう調整

### 色選択

- テキスト色、背景色、塗り潰し色、境界線の色の選択画面を整理
- 色パレットからの選択とPDF上からの色取得に対応
- 「色なし」を文字ボタンではなく斜線入りアイコンで表示
- 色なし表示の見切れを修正

### UI改善

- 図形選択ボタンを文字ではなく実際の図形アイコンで表示
- 図形選択ボタンの背景タイル表示を整理
- 拡大・縮小ボタンの記号位置を中央寄せ
- 拡大・縮小案内を半透明の曇りガラス風パネルに変更
- 編集画面のスクロールバーを必要時のみ目立つ表示に調整
