# 使い方マニュアル

## 触って覚える体験マニュアル

文章を読む代わりに、練習用のアプリ画面を操作しながら使い方を学べます。
`docs/interactive-manual/index.html` をWebブラウザで開いてください。インターネット接続は不要で、実際のPDFや画像は変更しません。

## 起動

`Offline PDF Converter.exe` をダブルクリックします。インターネット接続は不要です。

## 出力ファイル名の共通ルール

すべての機能で、出力ファイル名には元ファイル名が自動的に入ります。書き出しファイル名を指定した場合も、`元ファイル名_指定した名前`の順で保存します。複数ファイルを1つにまとめる場合は最大3件の元ファイル名を入れ、4件以上では長すぎる名前を避けるため`先頭2件_ほかN件_指定した名前`とします。

## PDFと画像を相互変換

画面上部の `PDF ↔ 画像` を選び、`変換方向` で処理内容を切り替えます。

### PDFを画像に変換

1. `変換方向` で `PDF → 画像` を選びます。
2. `追加` でPDFを選ぶか、PDFファイルを画面へドラッグ＆ドロップします。
3. 画像形式を `PNG` または `JPEG` から選びます。
4. 画質を `普通`、`高画質`、`超高画質` から選びます。
5. 必要なページだけ変換する場合は、`変換するページ` に `1,3,5-7` のように入力します。空欄の場合は全ページを変換します。
6. PDFがパスワード付きの場合は、追加時に表示されるポップアップへパスワードを入力します。
7. `出力先フォルダ` を選びます。
8. 必要に応じて書き出しファイル名を指定します。
9. `開始` を押します。

出力名の例:

```text
sample_converted_page001.png
sample_converted_page002.png
```

同名ファイルがある場合は、上書きを避けるため末尾に番号を付けます。

### 画像をPDFに変換

1. `変換方向` で `画像 → PDF` を選びます。
2. `追加` でJPEG/PNG画像を選ぶか、画像ファイルを画面へドラッグ＆ドロップします。
3. 必要に応じて `上へ` / `下へ` で順番を調整します。
4. ページサイズを選びます。
   - `A4縦`
   - `A4横`
   - `画像サイズに合わせる`
5. 余白を付ける場合は `余白あり` をオンにします。
6. 出力先と書き出しファイル名を指定します。
7. `開始` を押します。

## PDF編集

画面上部の `PDF編集` を選びます。

PDF編集画面では、追加したPDFのページプレビューが表示されます。結合前にページの順番を確認したり、ページ削除時に消したいページを見ながら選べます。

ページプレビュー右上の表示切り替えで、`アイコン` と `リスト` を選べます。

- `アイコン`: ページの見た目を小さなプレビューで確認したいときに使います。
- `リスト`: ページ数やファイル名を素早く確認したいときに使います。

### 複数PDFを結合

1. `操作` で `複数PDFを結合` を選びます。
2. `追加` でPDFを複数選ぶか、PDFファイルを画面へドラッグ＆ドロップします。
3. 必要に応じて `上へ` / `下へ` で結合順を調整します。
4. ページプレビューで結合後のページ順を確認します。
5. `結合後のPDF` で保存先とファイル名を指定します。
6. `開始` を押します。

### 1ページずつ分割

1. `操作` で `1ページずつ分割` を選びます。
2. 分割したいPDFを選びます。複数PDFをまとめて処理できます。
3. ページプレビューで分割対象のページを確認します。
4. `出力先フォルダ` を選びます。
5. 必要に応じて書き出しファイル名を指定します。
6. `開始` を押します。

出力名の例:

```text
sample_split_page001.pdf
sample_split_page002.pdf
```

### 選択ページを削除

1. `操作` で `選択ページを削除` を選びます。
2. PDFを1つだけ選びます。
3. ページプレビューで削除したいページにチェックを入れます。
4. `削除するページ` にページ番号が自動入力されます。直接入力もできます。
5. `出力PDF` で保存先とファイル名を指定します。
6. `開始` を押します。

入力例:

```text
1,3,5-7
```

元のPDFは上書きせず、指定ページを除いた新しいPDFを作成します。

### 選択ページのみ出力

1. `操作` で `選択ページのみ出力` を選びます。
2. PDFを1つだけ選びます。
3. ページプレビューで出力したいページにチェックを入れます。
4. `出力するページ` にページ番号が自動入力されます。直接入力もできます。
5. `選択ページのPDF` で保存先とファイル名を指定します。
6. `開始` を押します。

入力例:

```text
1,3
```

1ページ目と3ページ目を元の順番で並べた、2ページ構成のPDFを作成します。`3` のように1ページだけ指定した場合は、そのページだけを含む単独PDFを作成します。`1,3,5-7` のような範囲指定にも対応しています。

### 文字・テキストを追加

1. `操作` で `文字・テキストを追加` を選びます。
2. PDFを1つ選びます。
3. ページプレビューで編集したいページをクリックします。アイコン表示、リスト表示のどちらからでも編集画面を開けます。
4. `テキストボックスを追加` を押して、ページ上にテキストボックスを追加します。
5. テキストボックスをドラッグして移動し、周囲のハンドルでサイズを調整します。
6. フォント、文字サイズ、太字、下線、テキスト色、背景色を必要に応じて設定します。
7. 図形を追加する場合は、四角形、角丸四角形、丸、線から選びます。
8. 図形は移動、リサイズ、回転、塗り潰し色、境界線の色、境界線の太さを設定できます。色を付けない場合は斜線入りの `色なし` を選びます。
9. 編集画面右下の `+` / `-` で拡大・縮小できます。Ctrl+マウスホイール、トラックパッドのピンチ操作でも拡大・縮小できます。
10. 編集が終わったら `完了` を押します。
11. 複数ページを編集する場合は、別のページを開いて同じ手順で編集します。
12. すべての編集が終わったら、メイン画面で出力先と書き出しファイル名を指定し、`開始` を押します。

便利な操作:

- `Ctrl + C` / `Ctrl + V`: 選択中のテキストボックスまたは図形をコピー/貼り付け
- `Ctrl + Z`: 直前の編集を取り消し
- `Ctrl + B`: テキストを太字に切り替え
- `Ctrl + U`: テキストに下線を切り替え
- `Shift` を押しながら図形をリサイズ: 縦横比を保持
- `Shift` を押しながら線を調整: 45度刻みで角度を保持

### テキスト出力

1. `操作` で `テキスト出力` を選びます。
2. PDFを追加します。複数PDFをまとめて指定できます。
3. PDFがパスワード付きの場合は、追加時に表示されるポップアップへパスワードを入力します。
4. 全文を出力する場合は何も選択しません。ページ単位の場合は、プレビュー下の`ページ全体`へチェックを入れます。
5. ページ内の一部だけを出力する場合はプレビュー画像をクリックし、拡大画面上をドラッグして文字列を囲んでから`選択を確定`を押します。`Shift`、`Ctrl`または`⌘`を押しながらドラッグすると、選択範囲を追加できます。
6. 選択中の文字は`選択範囲のテキストをコピー`、Windowsの`Ctrl+C`、またはMacの`⌘C`でもコピーできます。
7. `出力テキスト（TXT）`で保存先とファイル名を指定し、`開始`を押します。

ページ番号と選択した文字をUTF-8のTXTファイルへ保存します。ページ全体のチェックと細かな文字選択を組み合わせられ、細かな選択があるページではその文字だけを出力します。画像だけで作られたPDFには文字情報がないため、この機能では選択・出力できません。画像PDFの文字認識にはOCRが必要です。

## パスワード付きPDF

保護されたPDFを追加すると、自動的にパスワード入力ポップアップが表示されます。正しいパスワードを確認できたPDFだけが一覧へ追加されます。キャンセルしたPDFは追加されません。

パスワードはPDFごとにメモリ上だけで保持し、アプリの設定やログへ保存しません。PDFを一覧から削除するか、`すべて削除` を押すと、そのPDFのパスワードも消去されます。複数PDFが異なるパスワードで保護されていても、それぞれの追加時に入力できます。閲覧用パスワードでは、PDFの権限設定によって編集できないことがあります。

## エラーが出た場合

- ファイルを他のアプリで開いている場合は閉じてください。
- 保存先に書き込みできるか確認してください。
- パスワードが違う、PDFが破損している、特殊な暗号方式や形式を使用している場合は処理できないことがあります。
- 単体exeが起動しない場合は、一時フォルダへの書き込み制限がないか確認してください。

## 改良版の追加機能

保存失敗への備え、個別再実行、用途別の出力設定、OCRは [改良版の使い方](IMPROVEMENTS.md) を参照してください。v3.2.0のWindows版はOCRも内蔵しており、追加インストールは不要です。
