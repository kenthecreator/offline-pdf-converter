# Offline PDF Converter (v5.2)

## 変更点

- ライト・ダーク両テーマで、操作ボタン、設定パネル、ファイルのドロップ欄、プレビューのガラス表現を選択ピルに合わせました。
- ライトテーマでは設定カードやプルダウンの面全体に屈折と反射を描きます。テーマを切り替えると新しい色で描画します。
- PDFの回転と最大16 in 1の配置編集、PDFの検索可能化を利用できます。

## 配布と検証

macOS Apple Silicon版はad-hoc署名で未公証、Windows x64版は未署名です。配布ZIPのSHA-256と、macOS・Windows Server 2022・Windows Server 2025での検証結果を添付します。
