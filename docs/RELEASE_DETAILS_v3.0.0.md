## Offline PDF Converter v3.0.0

選択ページ出力の追加と、アプリ全体のモノトーンUI・操作アニメーションを刷新したメジャーリリースです。

### 主な変更

- PDF編集の操作に `選択ページのみ出力` を追加
- `指定ページを削除` と同じページプレビューのチェックUIに対応
- `1,3,5-7` 形式で出力ページを直接指定可能
- 選択ページを元PDF内の順番で1つのPDFとして出力
- 1ページだけ選択した場合は、そのページだけを含む単独PDFとして出力
- ライト／ダークの両テーマをグラデーションのないモノトーンデザインへ刷新
- 全ボタンをピル型へ統一
- `PDF編集`／`PDF ↔ 画像`、変換方向、ページプレビュー表示形式を、1つのピルが移動するセグメントコントロールへ変更
- 各セグメントコントロールとテーマ切替を、クリックと横ドラッグの両方に対応
- テーマ切替時のピル移動と画面フェードの速度を統一
- ヘッダーを製品名だけのシンプルな構成へ変更し、ライト／ダーク専用のモノトーンアイコンを追加
- アプリおよびWindows `.exe` のアイコンをv3.0.0専用のモノトーンデザインへ更新
- 製品名、ウィンドウタイトル、画面ヘッダーの表示をv3.0.0へ更新

### 出力例

- 10ページのPDFで `1,3` を選択: 元の1ページ目と3ページ目を並べた2ページ構成のPDF
- 10ページのPDFで `3` を選択: 元の3ページ目だけを含む1ページ構成のPDF

### 補足

- 1ページずつ別ファイルへ保存する既存の分割機能とは異なり、選択ページを1つのPDFへまとめます。
- 完全オフライン動作、Adobe非依存、Windows x64向け単体実行形式の方針は継続します。
