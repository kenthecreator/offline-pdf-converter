## Offline PDF Converter v3.1.0

v3.1.0は、操作感と視認性を中心に磨き込んだUIアップデートです。

### 主な変更

- PDF→画像の解像度選択を、普通（200 dpi）・高画質（300 dpi）・超高画質（600 dpi）の3段階スライダーへ刷新しました。
- モード、変換方向、ページプレビュー表示、テーマ切替を、移動するピル型のセグメントUIへ統一しました。
- セグメント移動後もラベルがピルの中央に揃うように調整しました。
- テーマ切替を滑らかな色補間方式へ変更し、画面が消える・拡大したように見える現象とWindowsでのカクつきを抑えました。
- 狭いウィンドウでも製品名とバージョンを確認しやすい、左寄せのレスポンシブヘッダーへ変更しました。
- プルダウンをmacOS風の丸みを持つモノトーンデザインへ変更し、選択行にも角丸を適用しました。
- ライト／ダーク両テーマで解像度スライダーのつまみと目盛りを見やすくしました。
- 画像→PDFの空状態案内から不要な「＋」表示を削除しました。
- アプリ内表記、製品情報、Macアプリバンドルをv3.1.0へ更新しました。

### 配布物

- Windows x64 自己完結版
- macOS Apple Silicon 自己完結版（ad-hoc署名。Developer ID公証は未実施）
- 各ZIPのSHA-256チェックサム

完全オフラインで動作し、Python、Poppler、Adobe製品、外部変換サービスは不要です。
