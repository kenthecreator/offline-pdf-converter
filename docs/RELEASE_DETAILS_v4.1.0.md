# Offline PDF Converter (v4.1)

## Windows版のOCRを、追加ランタイムのインストールなしで

v4.1では、Windows版のOCRに必要なVisual C++ x64の実行部品をアプリのexeに同梱しました。Visual C++再頒布可能パッケージを別途インストールできない環境でも利用できる構成です。

OCRエンジン・認識モデル・.NET実行基盤も内蔵しています。初回起動を含め、OCRのためのネット接続や追加ダウンロードは不要です。配布する実行ファイルはexe一つで、必要な部品は起動時に利用者専用の一時領域へ自動展開します。Windows本体のOS部品と、一時領域への書き込みは必要です。

## 変更点

- 同梱マニュアルの古いランタイム導入案内を修正し、マニュアルから参照する「改良版の使い方」も配布ZIPに追加しました。

- Windows x64のVisual C++ release CRT DLLを未改変でexeに埋め込み、別途のランタイムインストールを不要にしました。
- OCR画面から、Visual C++ランタイムの事前インストールを求める案内を削除しました。
- OCR初期化の読み込みエラーを、ランタイム不足と断定しない案内に変更しました。
- Windows・Macともに、アプリ名、ウィンドウタイトル、アプリ内表示、配布ZIP名を「Offline PDF Converter (v4.1)」へ統一しました。内部バージョンは4.1.0です。
- 同梱DLLのハッシュと実際の読み込み元を検証し、システムのVisual C++ DLLを使っていた場合は自己検証を失敗させる仕組みを追加しました。

v4.0で導入した日本語（横書き・縦書き）／英語／日本語・英語混在のOCR、検索可能PDFの作成、PDF編集、PDFと画像の相互変換を引き続き利用できます。OCRモデルはv4.0と同じです。

## ダウンロード

- **Windows x64**：`Offline PDF Converter (v4.1)-Windows-x64.zip`。展開した`Offline PDF Converter (v4.1).exe`を起動します。
- **macOS Apple Silicon**：`Offline PDF Converter (v4.1)-macOS-arm64.zip`。展開した`Offline PDF Converter (v4.1).app`を起動します。ad-hoc署名で、Appleの公証は未実施です。
- 両ZIPのSHA-256確認用ファイルを添付します。

以前の**v4.0のタグ・リリース・配布ファイルは保持**しています。

## 検証範囲と制限

Windows Server 2025 x64では、exeだけを配置した新規フォルダと新規DLL展開先から、日本語・英語混在のOCRと検索可能PDF生成を確認しました。同梱CRTのハッシュと読み込み元も確認しています。さらに、Windows Firewallでテスト対象exeの送受信を全プロファイルで遮断した状態でも、初回OCRの自己検証が成功しました。

これはアプリ単位の通信遮断テストです。Windows 10/11の実機・Visual C++未導入のクリーンVM・ホスト全体のネットワーク切断・WindowsのGUI操作は未確認です。

OCRの精度と読み順は原本の画質・レイアウトに依存します。認識結果の直接修正は未対応です。既に文字を持つページはスキップします。元の暗号化・閲覧パスワードは出力PDFへ引き継ぎません。電子署名、目次、文書単位のフォーム構造の保持は保証しません。詳細は同梱マニュアルと`SEARCHABLE_PDF.md`を参照してください。
