## Offline PDF Converter v2.1.0

v2.0.0以降の変更を反映したリリースです。

### 主な変更

- PDF編集に「テキスト追加」機能を追加しました。
- PDFページのプレビュー上でテキストボックスを追加・移動・サイズ変更できるようにしました。
- テキストボックスは「テキストボックスを追加」ボタンを押した時だけ追加されるようにしました。
- テキストボックスの削除は、選択時に表示される「削除」ボタンからのみ行うようにしました。
- キーボードのDelete / Backspaceでテキストボックス自体が誤って削除されないようにしました。
- 複数ページに追加したテキストを一時保存し、まとめてPDFへ書き出せるようにしました。
- OS上で利用可能なフォントを選択できるようにしました。
- テキスト色と背景色を選択できるようにしました。
- 色選択では、パレットから選ぶ方法と、PDF上の色を拾う方法を利用できます。

### UI改善

- PDF編集の操作名を「注釈・簡易編集」から「テキスト追加」に変更しました。
- テキスト追加画面の右側パネルを整理し、macOS風の操作感に近づけました。
- 「テキストボックスを追加」ボタンのデザインを改善しました。
- 「フォント」「テキスト色」「背景色」などの表記を日本語に統一しました。
- 「完了」ボタンの文字サイズ、太字、中央配置、角丸を調整しました。
- 不要な整列ボタンや未使用の装飾ボタンを削除しました。
