# Offline PDF Converter (v5.0)

v5.0 ではモード切替・テーマ・変換方向・プレビューの選択ピル、各操作ボタン、PDF→画像の解像度バーと処理中の進捗バーにガラス調の描画を導入しました。暗い縁と明るい反射の強さは、ライト／ダークの背景に合わせて調整します。PDF のプレビューや保存される文書のピクセルは、従来の処理を使います。

- PDF・画像の変換、PDF 編集、PaddleOCR で検索可能 PDF を作成。
- Windows 10（1903以降）／11 x64 の単体 exe と macOS Apple Silicon のアプリを配布。
- アプリは必要な OCR モデルと実行部品を同梱。Mac 版は ad-hoc 署名です。

ZIP と同名の SHA-256 ファイルでダウンロードを確認できます。Windows Server 2022／2025 での自己検証結果を添付します。Windows 10／11 デスクトップと全種類の GPU での確認は別途必要です。
