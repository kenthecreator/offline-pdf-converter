# Offline PDF Converter (v5.5)

- macOSとWindowsで表示されるアプリアイコンを更新しました。
- メイン画面のヘッダーに表示されるアイコンを更新しました。

配布対象は macOS Apple Silicon と Windows x64 です。Office変換とOCRに必要なエンジンを同梱し、オフラインで動作します。Mac版はad-hoc署名・未公証、Windows版は未署名です。

検証結果とSHA-256は配布ZIPと同じリリースに掲載します。検証環境と範囲は [配布手順](https://github.com/kenthecreator/offline-pdf-converter/blob/v5.5.0/docs/DISTRIBUTION.md) を参照してください。
