# Offline PDF Converter (v5.4)

- 「PDF → 画像」「画像 → PDF」に続く第3タブ「Office → PDF」を追加しました。Word・Excel・PowerPointをファイル選択またはドラッグ＆ドロップで変換できます。
- 「Office → PDF」の右側でPDFの保存先フォルダーを指定できます。空欄の場合は各ファイルの元フォルダーに保存します。
- ライト／ダークで選択タブのガラス表現を調整しました。設定欄のスクロールバー、入力欄、ファイル一覧、プレビューの表示も更新しました。

配布対象は macOS Apple Silicon と Windows x64 です。Office変換とOCRに必要なエンジンを同梱し、オフラインで動作します。Mac版はad-hoc署名・未公証、Windows版は未署名です。

検証結果とSHA-256は配布ZIPと同じリリースに掲載します。検証環境と範囲は [配布手順](DISTRIBUTION.md) を参照してください。
