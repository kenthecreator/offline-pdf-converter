# Offline PDF Converter (v5.3)

## 変更点

- 「開始」ボタンにガラスの屈折と反射を適用しました。ライトでは暗いガラスに白文字、ダークでは明るいガラスに黒文字で表示します。
- ホバーするとわずかに浮き、押すと軽く沈みます。ホバーや押下中も文字のコントラストを保ち、上のパネルに隠れないよう描画順を調整しました。
- PDFから画像に変換する際の解像度スライダーで、バー、選択範囲、丸いつまみのガラス表現を揃えました。200・300・600 dpiを選べます。

## 配布と検証

macOS Apple Silicon版はad-hoc署名で未公証、Windows x64版は未署名です。配布ZIPのSHA-256と、macOS・Windows Server 2022・Windows Server 2025の検証結果を添付します。
