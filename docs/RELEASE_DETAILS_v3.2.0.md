# Offline PDF Converter v3.2.0

## 主な変更

- PDF・画像・TXTの保存を一時ファイルから確定する方式へ変更し、同名の既存ファイルを上書きしないようにしました。一括処理の結果表示、失敗分の再実行、中止、PDF→画像の用途別プリセットとJPEG品質設定を追加しました。
- 既存の文字レイヤーを持つPDFから、全ページ・指定ページ・プレビュー上のドラッグで選んだ文字をUTF-8 TXTへ出力できます。通常クリックは選択を解除し、ドラッグで選択します。Command/Ctrlで範囲を追加、Shiftで範囲を伸ばせます。
- スキャンPDF向けのOCRを追加しました。出力はTXTです。検索可能PDFの作成や、元PDFの文字の直接編集は行いません。
- Windows x64版にはTesseract 5.5.3と日本語（横書き・縦書き）・英語の認識データを内蔵しました。追加インストールや初回ダウンロードは不要です。初回OCR時に内蔵部品を一時フォルダへ展開し、SHA-256で検証します。
- macOS Apple Silicon版のOCRは、別途インストールしたTesseract 5を使用します。日本語・英語の認識データはアプリに含まれます。OCR以外のPDF・画像処理にTesseractは不要です。

## 配布物

- Windows 10（1903以降）／11 x64: 自己完結の単体exeを含むZIP
- macOS Apple Silicon: 自己完結のアプリを含むZIP。ad-hoc署名済み、Appleの公証は未実施
- 両ZIPのSHA-256チェックサム

両OSで配布ファイルの操作説明とライセンス情報を同梱しています。配布ページには最新版だけを表示します。

## 検証と制限

macOS arm64上の回帰テストは36件成功、0件失敗でした。日本語・英語の実OCRもMacにインストールされたTesseractで実行し、TXT出力を確認しました。MacアプリのGUIで、文字ドラッグ選択と文字・余白の通常クリックによる選択解除を確認しました。

Windows版はmacOSからクロスビルドし、exeが単一ファイルであること、ファイル版3.2.0.0、内蔵OCRアーカイブの存在とハッシュを検証しました。**Windows実機での起動・画面操作・内蔵OCR実行は未確認です。** GitHub ActionsのWindowsジョブは、公開後に別途結果を確認します。認識結果は原本と照合してください。
