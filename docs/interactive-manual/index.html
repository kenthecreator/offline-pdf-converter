ファイルを追加する

使いたいモードを選び、左側の 追加 からファイルを開きます。エクスプローラーからファイルを画面にドラッグしても追加できます。保護されたPDFには、追加時にパスワードを求められます。

削除 は選んだファイルを一覧から外し、すべて削除 は一覧を空にします。元のファイルは残ります。PDF一覧は3つのモードで共通です。用途を切り替えたら一覧を見直してください。

豆知識　実際のアプリでは、初期状態の Auto がWindowsのテーマに合わせます。太陽（☀）でライト、月（☾）でダークに手動で切り替えられます。このマニュアルとテスト機では、Auto をライト表示にしています。ヘッダーかテスト機の切替で、両方の表示が変わります。

PDF変換 → PDF → 画像

PDFをPNG・JPEG画像にする

  1. PDF変換 を開き、左側パネル上部の PDF → 画像 を選びます。追加 でPDFを選びます。複数のPDFも追加できます。
  2. 画像形式 を PNG または JPEG にします。変換するページ は空欄ですべて。必要なページだけなら 1,3,5-7 のように入力します。
  3. 解像度 は 普通（200 dpi）、高画質（300 dpi）、超高画質（600 dpi）から選びます。つまみをクリックまたはドラッグするか、フォーカスして左右キーで切り替えます。
  4. 出力先フォルダ の 選択 で保存先を決めます。必要なら 書き出しファイル名（元ファイル名を自動付加） を変え、開始 を押します。

出力例　資料_converted_page003.png。番号は元のPDFのページ順に対応します。

この操作を練習する

PDF変換 → 画像 → PDF

画像を1つのPDFにする

  1. PDF変換 を開き、左側パネル上部の 画像 → PDF を選びます。追加 でPNGまたはJPEG画像を選びます。
  2. 一覧がそのままPDFのページ順になります。画像を選び、上へ／下へ で並べ替えます。
  3. ページサイズ で A4縦、A4横、画像サイズに合わせる から選びます。余白が必要なら 余白あり をオンにします。
  4. 出力PDF の 選択 で保存先を決め、書き出し名を確認して 開始 を押します。

出力例　表紙.png、本文.jpgの順で 表紙_本文_converted_images.pdf。

この操作を練習する

PDF編集 → 操作 → 複数PDFを結合

PDFを結合する

  1. PDF編集 を開き、操作 で 複数PDFを結合 を選びます。追加 でPDFを2つ以上入れます。
  2. 一覧でファイルを選び、上へ／下へ で結合順に並べます。ページプレビュー で順番を確認します。見た目を確認するなら アイコン、ページ名を追うなら リスト が便利です。
  3. 結合後のPDF の 選択 で保存先を指定し、開始 を押します。
この操作を練習する

PDF編集 → 操作 → 1ページずつ分割

PDFを1ページずつ分割する

  1. PDF編集 の 操作 で 1ページずつ分割 を選び、追加 で分割するPDFを入れます。複数のPDFもまとめて処理できます。
  2. 出力先フォルダ の 選択 で保存先を指定します。必要なら書き出し名を変え、開始 を押します。

出力例　3ページの 資料.pdf から 資料_split_page001.pdf ～ 資料_split_page003.pdf を作ります。

この操作を練習する

PDF編集 → 操作 → 選択ページを削除

いらないページを削除する

  1. PDF編集 の 操作 で 選択ページを削除 を選び、一覧に対象のPDFを1つだけ残します。
  2. ページプレビュー で消したいページにチェックを入れます。削除するページ に直接入力することもできます。例えば 2 なら2ページ目を除きます。
  3. 削除後のPDF の 選択 で保存先を指定し、開始 を押します。出力を開き、必要なページが残っていることを確認します。

PDFに表示された印刷用のページ番号と違うことがあります。アプリではファイルの先頭を1ページ目として数えます。

この操作を練習する

PDF編集 → 操作 → 選択ページのみ出力

必要なページだけ取り出す

  1. PDF編集 の 操作 で 選択ページのみ出力 を選び、一覧に対象のPDFを1つだけ残します。
  2. ページプレビュー で取り出したいページにチェックを入れるか、出力するページ に入力します。
  3. 選択ページのPDF の 選択 で保存先を指定し、開始 を押します。1,3 なら1ページ目と3ページ目が元の順番で1つのPDFになります。

PDF編集 → 操作 → 文字・テキストを追加

PDFに文字・図形を追加する

  1. PDF編集 の 操作 で 文字・テキストを追加 を選びます。対象のPDFを1つだけ残し、ページプレビュー で編集するページをクリックします。
  2. 拡大編集画面の テキストボックスを追加 を押し、ページ上のボックスに入力します。右側で フォント、文字サイズ、テキスト色、背景色 を調整できます。
  3. 図形は 四角、角丸、丸、線 から選びます。塗り潰し色、境界線の色、境界線の太さ を調整できます。透明にしたい色は色選択画面の斜線入りの 色なし を使います。
  4. 文字・図形はドラッグで移動し、周囲のハンドルでサイズを調整します。図形は回転ハンドルも使えます。完了 で戻り、必要なら別のページも編集します。
  5. メイン画面の 編集後のPDF の 選択 で保存先を指定し、開始 を押して書き出します。

Windowsの操作　ページ上でオブジェクトを選び Ctrl＋C／Ctrl＋V でコピー・貼り付け。Ctrl＋Z で取り消し、Ctrl＋B／Ctrl＋U で太字／下線。拡大・縮小は ＋／− または Ctrl＋マウスホイール。図形のサイズ調整中に Shift を押すと縦横比を維持し、線の端点を動かす場合は45度刻みになります。

この操作を練習する

PDF編集 → 操作 → 複数ページを1枚に配置

複数ページを1枚に配置する

  1. PDF編集 にPDFを1つ追加し、操作 で 複数ページを1枚に配置 を選びます。配置したPDF の 選択 で保存先を設定します。
  2. 開始 で 複数ページのレイアウト編集 を開きます。2・4・6・9・16 in 1から1枚に置くページ数を、A4 横／A4 縦 から用紙方向を選びます。
  3. 前へ／次へ で用紙を切り替えます。各ページはドラッグで移動し、右下の青いハンドルで拡大・縮小します。この用紙の配置をリセット で表示中の用紙を初期配置に戻せます。
  4. PDFを保存 を押し、保存したPDFで用紙数と各ページの位置を確認します。

用紙方向や配置数を変更すると、全用紙の配置が初期化されます。位置や大きさの手直しは、用紙と配置数を決めてから行うとスムーズです。

PDF編集 → 操作 → ページを回転

PDFのページを回転する

  1. PDF編集 にPDFを1つ追加し、操作 で ページを回転 を選びます。回転したPDF の 選択 で保存先を設定します。
  2. 開始 で回転画面を開きます。前へ／次へ で対象ページを表示します。
  3. 左に90° または 右に90° を押します。全ページに同じ操作を適用するときは、先に 全ページを回転 にチェックを入れます。回転ボタンを押すたびに、90度ずつ追加で回転します。
  4. ページの向きをプレビューで確認し、PDFを保存 を押します。
この操作を練習する

OCR処理 → PDFのOCR処理

検索できるPDFを作る

  1. OCR処理 を開き、追加 でスキャンPDFを入れます。処理前 で対象を確認します。
  2. PDFの言語 で 日本語（横書き）、日本語（縦書き）、英語、日本語・英語 混在 から選びます。
  3. 認識するページ は空欄で全ページです。1,3 などの指定は一覧のすべてのPDFに適用されます。プレビューで見ているページとは別の設定です。全ページに戻す で指定を解除できます。対象外のページも出力PDFに残ります。
  4. PDFの保存先 の 保存先を選択 でフォルダを指定し、開始 を押します。
  5. 完了後、処理後 のページをクリックし、文字をドラッグで選びます。選択した文字をコピー または Ctrl＋C でコピーできます。Ctrl＋A で全選択、Esc で選択を解除します。Ctrl を押しながらドラッグすると追加選択、Shift で範囲を拡張できます。拡大・縮小は ＋／− または Ctrl＋マウスホイールです。完了 で戻ります。

出力例　資料_OCR.pdf。保存したPDFを開き、Ctrl＋F で用語を検索して確認できます。

OCRはページの見た目を保ったまま検索用の文字を追加します。本文に既存の文字があるページは保持されます。短いページ番号やヘッダー／フッターだけが文字の場合は、画像の本文もOCRします。白紙や文字を検出できなかったページには文字を追加しません。数字・単位・漢字など、重要な内容は原本と照合してください。v5.5のOCRの保存形式はPDFです。

この操作を練習する

テスト機で練習する

テスト機にはPDFと画像の見本があります。「次の操作」の案内を読み、光っているボタンや入力欄を順に操作します。この画面では見本ファイルを使い、結果もブラウザー内に表示します。

次の操作

保存結果・中止・再実行

  1. 完了 または 一括処理の結果 で、件数とメッセージを見ます。PDF → 画像、PDF分割、OCRでは入力ごとに成功・失敗・中止・未処理が表示されます。
  2. Windows＋E でエクスプローラーを開き、保存時に指定したフォルダを開きます。変換は枚数・並び順、編集はページ数と変更内容、OCRはPDFビューアーでの検索・コピーを確認します。
  3. 元ファイル名が出力名に入り、同名の出力があると _2 などの連番が付きます。PDFを1つ書き出す操作では、書き出しファイル名 に値があればその値がファイル名の指定として優先されます。

途中で止める　処理中の 処理を中止 を押し、停止するまで待ちます。すでに保存されたファイルは保存先に残ります。分割や画像出力では、途中までのページが残る場合があります。

やり直す　一括処理の結果で 失敗だけ再実行 または 中止・未処理を再実行 を選びます。対象ファイルの処理を先頭からやり直し、同名の保存済み出力は別名になります。設定を直したいときや個別の再実行ボタンがない操作では、結果を閉じて設定を確認し、対象を一覧に残して 開始 を押します。

OCR出力には元の暗号化や閲覧パスワードが引き継がれません。署名・目次・文書全体に関わるフォームの保持も保証されないため、必要なときは原本を保管してください。

よくある困りごと

「出力先」や「PDFの保存先」が見えない

右側の設定欄にマウスを置いて下へスクロールします。変換方向は PDF変換 画面の左側パネル上部にあります。

保存したファイルが見つからない

画面に表示された保存先をエクスプローラーで開き、更新日時順に並べます。指定した名前の前に元ファイル名、後ろにページ番号や同名時の連番が付くことがあります。

ファイルを追加・処理できない

選んだモードとファイル形式を確認します。画像→PDFはPNGとJPEGです。PDFが保護されていれば正しいパスワードを入力します。パスワード入力を取り消すと一覧に追加されません。閲覧用パスワードで開けても編集が制限されるPDFがあります。別のアプリで使用中なら閉じ、状態の分かっているファイルで試してください。

ページ番号の指定でエラーになる

PDFの先頭を1として、半角の数字・カンマ・ハイフンで 1,3,5-7 のように入力します。複数のPDFに共通の範囲を指定したときは、最も短いPDFのページ数も確認します。削除で全ページを指定すると保存できません。

文字や図形を加えたのにファイルが変わっていない

拡大編集画面で 完了 を押したあと、メイン画面でも 開始 を押します。編集後のPDF で指定した場所の新しいファイルを開きます。

OCR後に文字を検索できない、読み違いがある

開いているのが _OCR.pdf か、該当ページを認識対象にしたかを確認します。言語と縦書き・横書きの選択を見直します。スキャンが不鮮明な場合は、読みやすい原本から作り直すと改善することがあります。認識した文字はアプリ内で直接修正できません。

ページ配置や回転を選んでも編集画面が開かない

PDFは1つだけ追加し、右側で保存先を設定して 開始 を押します。専用画面の キャンセル で保存せずに戻れます。

保存できない、処理を止めてもすぐに戻らない

空き容量とフォルダへの書き込み権限を確かめます。デスクトップやドキュメント内の自分で書き込めるフォルダを指定して試せます。処理を中止 を押したときは、現在のページ処理を抜けるまで時間がかかることがあります。
