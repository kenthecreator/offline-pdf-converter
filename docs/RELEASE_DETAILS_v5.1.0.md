# Offline PDF Converter (v5.1)

- **OfficeファイルをPDFに変換** — Word（`.docx`）、Excel（`.xlsx`）、PowerPoint（`.pptx`）をドロップするか、「Officeファイルを追加…」で選択します。元ファイルと同じフォルダーに、透かしのないPDFを保存します。変換エンジンはアプリに同梱されています。
- **複数ページを1枚に配置** — PDF編集で2・4・6・9・16 in 1、A4縦・横を選べます。プレビューでページの位置とサイズを個別に調整できます。
- **ページを回転** — 選択ページまたは全ページを左右に90度ずつ回転し、PDFに保存できます。

Office変換では共通の互換書体を使用します。検証に使ったWord原稿では、Mac版とWindows版のPDFで表と画像の縦位置に約1.7 mmの差がありました。原稿の書体や機能によっては、出力後の改行や配置が変わることがあります。

対応端末はmacOS Apple SiliconとWindows 10（1903以降）／11 x64です。Mac版はad-hoc署名で未公証です。Windows版は単体exeです。
