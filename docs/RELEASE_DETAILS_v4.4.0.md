# Offline PDF Converter (v4.4)

トリミングされたPDFのOCR判定と、日本語テキストの保存時の折り返しを修正しました。完全オフライン・Windowsのexe単体動作を維持します。

## 修正内容

- PDFのトリミング範囲（CropBox）の外に残る文字を、既存本文の判定から除外しました。隠れた文字が原因で表示中の本文のOCRが省略される問題を解消します。既存の可視文字層は引き続き保持します。
- 編集画面では折り返して表示される長い日本語が、保存PDFでは一行になりテキストボックスからはみ出す問題を修正しました。日本語・英語の折り返し、明示的な改行・空行、行ごとの左・中央・右揃え、ボックス範囲でのクリップを保存時に適用します。
- 公開済みv4.2／v4.3専用ワークフローの自動実行を停止し、現在のバージョンの配布名で検証します。過去のタグ上のソース・ワークフローとリリースは保持します。
- Windows・macOSの表示、タイトル、配布名をv4.4に統一しました。内部バージョンは4.4.0です。

v4.3の小さい日本語の改善（A4 300dpi・OCR検出上限4096px、数字だけのフッターがあっても本文をOCR、既存文字の重複抑止）と、Noto Sans Japaneseを内蔵した非表示文字層を引き継ぎます。OCRモデルは変更していません。

## 検証

修正前に両方の不具合を再現し、修正後に追加した回帰テストで確認しました。0・90・180・270度の回転とCropBox、文字位置、入力・出力の100dpi全画素一致、日本語の折り返し、改行・空行・行ごとの整列を検証します。

公開前のCIでは、保存保護・中止・結合・分割・抽出・画像変換等の回帰テスト、4言語の検索可能PDF、6ポイントの日本語表・青い文字・数字だけのフッター、完成済み文字層と短いデジタル本文の保持を実行します。

Windows Server 2022／2025では、同一の配布exeを新規フォルダ・新規展開先へ配置し、Windows Firewallで対象exeの送受信を遮断して機能と実ウィンドウ操作を検証します。macOS arm64版も検索可能PDF・小文字・配布アプリの機能を検証します。全ゲートに成功した配布物のみ公開します。

## ダウンロードと保持

- Windows x64：`Offline.PDF.Converter.v4.4.-Windows-x64.zip`。展開した`Offline PDF Converter (v4.4).exe`を起動します。
- macOS Apple Silicon：`Offline.PDF.Converter.v4.4.-macOS-arm64.zip`。展開した`Offline PDF Converter (v4.4).app`を起動します。ad-hoc署名で、公証は未実施です。
- 各ZIPのSHA-256とWindowsでの検証結果JSONを添付します。

v4.4.0を新規追加し、v4.3.0を含む既存のリリース・タグ・配布ファイルは削除・上書きしません。

Windows版は.NET、OCRモデル、ONNX実行部品、Visual C++ CRT、必要なフォントをexeに含めます。利用時のネット接続・追加ランタイム導入・初回ダウンロードは不要です。Windows OS部品と一時領域への書き込みは必要です。開発時だけ固定版のフォントを生成します。

## 制限と検証範囲

OCRの完全な正確性を保証するものではありません。一部の漢字・句読点・上付き文字等に誤認識が残るため、数値・単位等は原本と照合してください。複雑な表の読み順・選択位置は近似で、認識結果の直接修正は未対応です。

本文の一部に既存文字層があるページを全面的に再OCRする機能ではありません。元の暗号化・閲覧パスワードは出力に引き継ぎません。署名・目次・文書単位のフォーム構造の保持は保証しません。

Windows 10／11の実機、Visual C++未導入のクリーンVM、PC全体のネットワーク切断はCIとは別の未確認項目です。GUI検証は実ウィンドウと操作イベントの自動検証で、すべてのマウス・タッチ・OSファイル選択操作を網羅しません。
