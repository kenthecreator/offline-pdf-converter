# Offline PDF Converter (v4.0)

## スキャンしたPDFを、検索できる資料へ

v4.0では、Mac・Windowsの両方に**オフラインOCR**を導入しました。画像だけのPDFを認識し、原本のページの見た目を保ちながら、**検索・選択・コピーできる文字レイヤー付きPDF**を生成します。

書類を外部サービスに送らず、この端末だけで処理できます。PaddleOCRエンジンと認識モデルをアプリに内蔵し、OCRのためのネット接続・初回モデルダウンロードは不要です。Tesseract・Python・GPUの別途インストールも不要です。

## OCRの主な機能

- **4種類の「PDFの言語」**：日本語（横書き）、日本語（縦書き）、英語、日本語・英語 混在。それぞれに適した認識モデル・読み順で処理します。
- 複数PDFの一括処理、`1,3,5-7`形式のページ指定、パスワード付きPDFの入力に対応します。
- 対象外のページも残して新しいPDFを保存します。既存文字のあるページは文字レイヤーを重複させずに保持します。
- 同名の出力は連番にして保存し、原本や既存の出力を上書きしません。

## 結果を確認しやすい、新しい画面

- 「処理前」「処理後」を左右に表示。アイコン／リスト切替とスクロールを連動します。
- 処理後のプレビューを開くと、実際のPDF内の文字を選択・コピーできます。PDF編集と揃えた画面で、拡大・縮小、全選択、選択解除に対応します。
- 対象ページすべてにスキャン演出を同時表示し、短時間で終わっても最低5秒間表示します。完了後はスキャンを終了し、ピンク・紫・青の間接照明と緑の丸いチェックで結果を示します。
- 操作ボタンを「開始」に統一。PDF編集と同じ滑らかな表示切替を採用しました。
- 初期テーマを「Auto」とし、デバイスのライト／ダーク設定に追従します。
- OCRの導入を表す新しいアプリアイコンをMac・Windowsの両版に採用しました。
- アプリ名・タイトルを「Offline PDF Converter (v4.0)」に統一しました。

PDF編集の従来の文字抽出・TXT出力は廃止し、OCRで検索可能PDFを作成する流れに統一しました。PDF編集、PDF↔画像変換などの既存機能も引き続き利用できます。

## ダウンロードと動作条件

- **Mac**：`Offline PDF Converter (v4.0)-macOS-arm64.zip`（Apple Silicon）
- **Windows**：`Offline PDF Converter (v4.0)-Windows-x64.zip`（Windows 10 1903以降／11、x64）

ZIPを展開してアプリを起動します。Windows版は単体exeで.NETランタイムを内蔵しますが、**Microsoft Visual C++ v14（x64）ランタイムが必要**です。Mac版はad-hoc署名で、Appleの公証は未実施です。ZIPごとのSHA-256を添付しています。

## 確認範囲と注意点

macOSでOCRの4言語設定、検索可能PDF、ページ指定、既存文字の重複防止、取消、同名出力保護、パスワード付き入力を検証しました。9ページの入力・出力を100dpiで比較し、見た目が画素単位で一致することを確認しています。文字選択・コピー、連動スクロール、表示切替、処理演出もmacOSの実画面で確認しました。Windows版はビルド・配布構成に加え、Windows CIで日本語OCRと検索可能PDFを含む単体exeの自己検証が成功しました。Windows実機での画面操作は未確認です。

OCRの精度や読み順は原本・画質・レイアウトに依存します。細かな文字選択位置は近似で、複雑な表や段組の完全な再現は保証しません。認識結果の直接修正は未対応です。既に文字を持つページはスキップします。新しいPDFには元の暗号化・閲覧パスワードを引き継ぎません。電子署名・目次・文書単位のフォーム構造の保持は保証しません。
