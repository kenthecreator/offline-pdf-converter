# Offline PDF Converter (v4.3)

ページ番号だけが文字で本文が画像・輪郭線のPDFでも本文をOCRできるようにし、小さい日本語文字の細部を保持するよう改善しました。完全オフライン・Windowsのexe単体動作を維持します。

## 改善内容

- ページ番号など1文字が存在するだけでページ全体をOCR対象外にしていた判定を修正しました。上下10%の余白だけに64文字以下の文字がある場合は本文をOCRします。本文に既存文字層があるページは引き続き保持します。
- 既存のページ番号・ヘッダー／フッターと位置・内容が一致する認識結果を除外し、二重に文字を追加しません。完成済みの文字層も重複させません。
- OCR検出前の画像縮小上限を長辺2000pxから4096pxへ拡張しました。通常のA4は300dpiの画像を保持し、細かな日本語の画線を失いにくくしました。大判ページの画像生成は長辺4096px以内を目安に制限します。
- OCRの非表示文字層にNoto Sans Japanese（Noto Sans JP Regular）を内蔵しました。SIL OFL 1.1の全文・取得元・生成方法・SHA-256を同梱します。
- Windows・Macの表示、タイトル、配布名をv4.3に統一しました。内部バージョンは4.3.0です。OCRモデルはv4.2と同じです。

## 検証

提供された小さい日本語の表のPDFを改良した処理経路で検証し、本文中の日本語8箇所を検索できること、ページ番号を重複させないこと、入力と出力が100dpiで全画素一致することを確認しました。元PDFでは本文の文字層がなく、既存文字はページ番号「2」だけでした。元PDFはリポジトリ・配布物に含めません。

公開前のCIでは6ポイントの日本語表と青い文字、ページ番号のみが文字のPDF、完成済み文字層の保持、短いデジタル本文の保持を検証します。従来の検索可能PDF・4言語・取消・保存保護・PDF編集等の回帰検証も実行します。

Windows Server 2022／2025では、実際の配布exeを新規フォルダ・新規展開先へ配置し、Windows Firewallで対象exeの送受信を遮断して機能・実ウィンドウ操作を検証します。Mac版も検索可能PDF・小文字・配布アプリの機能を検証します。全ゲートに成功した配布物のみ公開します。

## ダウンロードと保持

- Windows x64：`Offline.PDF.Converter.v4.3.-Windows-x64.zip`。展開した`Offline PDF Converter (v4.3).exe`を起動します。
- macOS Apple Silicon：`Offline.PDF.Converter.v4.3.-macOS-arm64.zip`。展開した`Offline PDF Converter (v4.3).app`を起動します。ad-hoc署名で、公証は未実施です。
- 各ZIPのSHA-256とWindowsでの検証結果JSONを添付します。

既存のリリース・タグ・配布ファイルは削除・上書きしません。v4.3.0を新規追加します。

Windows版は.NET、OCRモデル、ONNX実行部品、Visual C++ CRT、必要なフォントをexeに含めます。利用時のネット接続・追加ランタイム導入・初回ダウンロードは不要です。Windows OS部品と利用者の一時領域への書き込みは必要です。開発時だけ固定版のフォントを生成します。

## 精度と検証範囲

完全に正確な認識の保証ではありません。今回のPDFでも平方メートルの上付き「²」、一部の漢字・句読点の誤認識が残ります。数値・単位・手続き基準等は原本と照合してください。複雑な表の読み順と選択位置は近似で、認識結果の直接修正は未対応です。

ページ番号のみのページを自動判別する改善であり、本文の一部に既存文字層があるページを全面的に再OCRする機能ではありません。元の暗号化・閲覧パスワードは出力に引き継ぎません。署名・目次・文書単位のフォーム構造の保持は保証しません。

Windows 10／11の実機、Visual C++未導入のクリーンVM、PC全体のネットワーク切断はCIとは別の未確認項目です。GUI検証は実ウィンドウと操作イベントの自動検証で、すべてのマウス・タッチ・OSファイル選択操作を網羅しません。
