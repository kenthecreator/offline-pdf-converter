# v4.3: OCRで検索可能なPDFを作成

OCR処理はTXT保存からPDF保存に変更しました。PDF編集の「テキスト出力」と文字範囲選択の画面は廃止しました。OCR画面の言語選択は「PDFの言語」とし、日本語（横書き）／日本語（縦書き）／英語／日本語・英語 混在の4項目を用意しています。

認識した文字をPDFの非表示文字レイヤーとして追加します。PDFsharpで原本のページを読み込み、画像やベクトルの描画内容を再圧縮・画像化せずに保持します。ページ指定は文字を追加する対象で、対象外のページも出力へ残します。同名出力の保護・中止・一括結果・再実行を維持します。

日本語2項目は日本語用PP-OCRv4、英語は英語用PP-OCRv4、混在はPP-OCRv6 smallを使います。日本語縦書きでは列の順序と文字位置も縦書きに合わせます。認識モデルと辞書は固定したSHA-256で検証して埋め込みます。専用モデルで精度向上を保証するものではありません。モデルの出典は[RapidOCR公式の固定版一覧](https://github.com/RapidAI/RapidOCR/blob/v3.9.2/python/rapidocr/default_models.yaml)です。

## 保持と制限

- 本文に既存の文字があるページは保持します。上下10%の余白だけに64文字以下のページ番号・短いヘッダー／フッターがある場合は本文をOCRします。既存文字と位置・内容が一致する認識結果は追加しません。
- 通常のA4は300dpiでレンダリングし、検出前の縮小上限を2000pxから4096pxへ拡張しました。大判ページの画像生成は長辺4096px以内を目安に制限します。
- 非表示文字層には内蔵Noto Sans Japanese（Noto Sans JP Regular、SIL OFL 1.1）を使用します。
- 白紙や認識できなかったページは原本のままです。そのページには検索できる文字が追加されません。
- 行の認識矩形から文字位置を推定します。細かな選択位置は近似で、傾き・ルビ・複雑な表や段組の完全な再現は保証しません。
- 出力に元の暗号化や閲覧パスワードは引き継ぎません。ページのコピーによる新しいPDFのため、署名・目次・文書単位のフォーム構造などの保持は保証しません。
- 書き出したPDFの文字や読み順は原本と照合してください。認識結果の直接修正は今回追加していません。

## 検証

専用テストは日本語・英語の抽出、縦書き、4項目のモデル切替、ページ指定、白紙、既存文字の重複防止、同名ファイル保護、中止、パスワード付き入力を検証します。9ページの出力と入力を100dpiでレンダリングし、全画素が一致することも確認します。

```sh
dotnet build tests/SearchablePdfTests -c Release -p:PaddleOcrEdition=true
dotnet artifacts/paddle-edition/bin/SearchablePdfTests/Release/net8.0/SearchablePdfTests.dll "$PWD" "$PWD/artifacts/new-searchable-checks"
```

旧版のTXT認識精度の測定結果は今回のPDF出力・言語別モデルとは別の評価です。Windows Server 2022／2025の配布exeの機能・実ウィンドウ操作はCIで検証します。Windows 10／11の実機での操作は未確認です。

## 処理前・処理後の確認

OCR画面のプレビューは、左に処理前、右に今回保存した処理後のPDFを表示します。共通のアイコン／リスト切替で左右の表示を連動させ、ページをクリックすると拡大画面を開けます。処理前の拡大画面は表示と拡大・縮小だけに絞ります。処理後は実際のPDFの文字層を読み込み、ドラッグで文字を選択できます。Ctrl/Cmdを押しながらドラッグすると追加選択、Shiftを押すと範囲を拡張します。Ctrl+C（Macでは⌘C）またはコピーボタンで選択文字をコピーします。Ctrl+A／⌘Aは全選択、Escは解除です。文字を持たないページでは選択できない旨を表示します。拡大画面は確認・文字選択用で、PDFの内容は変更しません。

表示切替はPDF編集と同じスライドアニメーションで動き、左右のプレビューのスクロール位置も連動します。「開始」で処理すると、対象ページすべての処理前プレビューに同時にスキャンの演出を表示し、短時間で完了しても結果ポップアップまで最低5秒間表示します（中止した場合は待機を終了）。処理前の演出を終了してから、処理後にカードの背面から鮮やかなピンク・紫・青の光が漏れる、約10秒周期の間接照明のglow演出を表示します。処理後のアイコン・リストには、緑の丸に白いチェックの完了マークを継続して表示します。端末で視差効果を減らす設定が有効な場合は、動きを抑えた静止表示になります。

処理後の文字確認画面は、PDF編集の「文字・テキストを追加」と同じ左右配置、右下の拡大・縮小パネル、右側に固定した「完了」ボタンを使います。右側には文字選択・選択結果・コピー操作を配置し、文字追加やフォント・図形の設定は表示しません。ピンチ操作とCtrl/⌘＋ホイールでも拡大・縮小できます。
